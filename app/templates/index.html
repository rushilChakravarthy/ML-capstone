Evaluation Metrics

Algorithm Silhouette (↑) Davies-Bouldin (↓) Ground-Truth ARI
K-Means Winner 0.2717 1.6360 0.6576
Agglomerative (Ward) 0.2530 1.7088 0.5954

Key Methodological Insights:

  • Unanimous Agreement: K-Means achieves superior cohesion (higher Silhouette) and tighter separation (lower Davies-Bouldin).
  • Linkage Degeneracy: Single linkage produced artificial silhouette scores due to chaining (99.9% single cluster). Ward's minimum variance is the only valid linkage.
  • External Ground-Truth (ARI = 0.6576): The unsupervised partition matched official transport categories without ever seeing class labels.

This project investigates multi-track machine learning applications in vehicle credit risk underwriting, unsupervised transport fleet clustering, and secondary automotive market price valuation. All models were trained strictly using scikit-learn on verified real-world datasets with comprehensive cross-validation and reproducible serialization pipelines.
